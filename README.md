# 🧸 USA Play Room Specification (Ігрова кімната)

Табличний інтерактивний варіант специфікації товарів та меблів для дитячої ігрової кімнати (США).

## 📌 Огляд проєкту
Сайт створений на основі наданих дизайн-специфікацій з PDF-документів (`Copy of Игрова сша мебель  (1).pdf` та `_Игрова сша мебель  3 (1).pdf`).

### ✨ Основні можливості:
- **Повний перелік товарів (14 позицій, 18 одиниць)** з прямими посиланнями на магазини (IKEA, Amazon, West Elm, Etsy, Hovia).
- **Зручна фільтрація за категоріями**:
  - 🪑 Меблі (4)
  - 💡 Освітлення (2)
  - 🌿 Текстиль (2)
  - 🧱 Стіни та оздоблення (2)
  - 🤸 Спорт та активність (4)
- **Миттєвий пошук** за назвою, категорією, магазином чи коментарем (гаряча клавіша `/` для швидкого фокусу).
- **Інтерактивний Lightbox**: клік по зображенню відкриває повноекранний перегляд фото та детальний опис.
- **Друк / Збереження в PDF**: кнопка `🖨️ Друк / PDF` з оптимізованими стилями друку A4.
- **Адаптивний дизайн**: зручний перегляд на мобільних пристроях, планшетах і ПК.

## 🚀 Структура проєкту
- `index.html` — основна розмітка та логіка
- `styles.css` — стилізація, кольорова гама та print-стилі
- `app.js` — дані товарів та інтерактивні функції
- `images/` — фотографії та візуалізації товарів
- `vercel.json` — конфігурація для деплою на Vercel
